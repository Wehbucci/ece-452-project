# Null Pointers

### Procject Description 
A learning path app that turns a broad topic into a clear, manageable study plan. Users enter what they want to learn, and the app generates a sequence of subtopics with quick, engaging summaries so learners can see what’s important and why it matters. It also lets users save subtopics to revisit and provides helpful resource links like Wikipedia, books, or articles for deeper exploration. This makes starting a new subject easier and less overwhelming.
